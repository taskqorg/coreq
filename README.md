# coreq

Shared infrastructure crate of taskqorg tools: release and update, launcher and rollback, service (launchd, Scheduled Task, systemd), `status.json`, selftest harness, incident reports, profiling, telemetry and bounded process execution. [AgentQ](https://github.com/taskqorg/agentq/blob/main/docs/spec/RUNTIME.md) owns Claude and Codex agent runtimes and uses CoreQ primitives. Extracted from [taskq](https://github.com/taskqorg/taskq) v4. Decisions live in coreq.md; releases follow the [specq release contract](https://github.com/taskqorg/specq/blob/main/engineering/release-contract.md). taskq is the reference consumer; pin an immutable crate release from CHANGELOG.md. The v0.19.0 [source boundary](docs/design/agent.md) removes `coreq::agent`; old consumer builds retain their original pins.
