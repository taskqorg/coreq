# Security

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/taskqorg/coreq/security/advisories/new). Do not open a public issue.

The maintainer acknowledges a report within 7 days and shares a fix plan or a decision within 30 days.

This repository follows the [specq security baseline](https://github.com/taskqorg/specq/blob/main/engineering/security.md).
